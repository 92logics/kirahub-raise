# KIRAHub RAISE SME assistant (prototype)

Prototype by [92 Logics](https://www.92logics.com) for the KIRAHub RAISE project, Lots I and II. It is not a bid and not an official system. Scripted answers only.

## What it shows

A public sample of a scripted assistant for a small business: summarize a renovation project note, draft a follow-up to a partner, or turn a site checklist into steps. It is for Central Baltic SME pilots in spirit only. It is not connected to any KIRAHub system. Nothing calls a live AI API.

Questions close 8 October 2026 at 16:00. The offer closes 18 October 2026 at 00:00 EEST. This page does not state budgets or pilot counts.

## Run it

Open `index.html` in a browser, or use the GitHub Pages copy. No install and no build step.
